## 📌 About

- A responsive weather application built using **HTML, CSS, and JavaScript** that fetches real-time weather information using the **OpenWeather API**.

- Users can search for a city and view its current temperature, humidity, wind speed, and weather condition through a clean and interactive interface.

---

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature information
- 💧 Humidity percentage
- 💨 Wind speed
- ☁️ Dynamic weather icons
- 🎨 Dynamic background based on weather conditions
- 🔍 Search button functionality
- ⌨️ Enter key support
- ⚠️ Invalid city error handling
- ⏳ Loading indicator
- 📱 Responsive design
- ✨ Smooth animations and hover effects

## 🌐 How It Works

1. Enter a city name in the search box.
2. Click the search button or press **Enter**.
3. The application sends a request to the OpenWeather API.
4. Weather data is retrieved from the API.
5. The application displays:
   - 🌡️ Temperature
   - 💧 Humidity
   - 💨 Wind Speed
   - 🌦️ Weather Condition
6. The background and weather icon change according to the current weather condition.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Dibyar21/weather-app.git
```

### 2. Navigate to the project

```bash
cd weather-app
```

### 3. Add your OpenWeather API key

Replace the API key in the JavaScript code with your own restricted API key.

### 4. Open the project

Open `index.html` in your browser.

No additional packages or dependencies are required.

---

## 🔐 API

This project uses the **OpenWeather API** to retrieve real-time weather information.

> ⚠️ Never commit an unrestricted API key to a public GitHub repository.

For production applications, use a backend/serverless function to keep API credentials secure.
